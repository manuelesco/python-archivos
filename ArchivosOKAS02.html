Manejo de Archivos

Lee y escribe archivos de texto y CSV

Trabajar con archivos es una habilidad fundamental en cualquier lenguaje de programación. En Python, el manejo de archivos es especialmente sencillo y expresivo. Los dos tipos más comunes en el mundo del desarrollo y análisis de datos son:

  • Archivos de texto plano (.txt) — almacenan datos como secuencias de caracteres legibles.
  • Archivos CSV (.csv) — Comma-Separated Values (Valores Separados por Comas), un estándar para tablas de datos donde cada fila es una línea y los valores se separan por comas (u otro delimitador).

Python ofrece herramientas nativas para ambos: la función built-in open() para texto, y el módulo estándar csv para archivos CSV.

📂

Apertura de Archivos

Conoce la función open()

📂 Apertura de Archivos

La función integrada open() abre un archivo y regresa un objeto de archivo (file object) con el que puedes leer, escribir o manipular su contenido. No lee ni escribe nada por sí sola, simplemente establece la conexión entre tu programa y el archivo en el disco. Una vez abierto, debes usar los métodos del objeto (read(), write(), etc.) para trabajar con él.


La forma moderna y segura de abrir archivos en Python es utilizando la sentencia with, que trabaja con un gestor de contexto (context manager) que se encarga de ejecutar acciones de configuración al entrar en el bloque y de limpieza al salir, sin importar si ocurre un error o no.
También garantiza que el archivo se cierre automáticamente al terminar el bloque with, aunque ocurra una excepción. Elimina la necesidad de llamar archivo.close() manualmente.

🔤 Sintaxis

with open(file, mode='r', encoding=None, errors=None) as variable_archivo:
	# Bloque de código para trabajar con el archivo
	...

# Aquí el archivo ya fue cerrado automáticamente

Donde:

Parámetro Descripción
file Ruta del archivo (relativa o absoluta)
mode Modo de apertura
encoding Codificación del texto ('utf-8', 'latin-1', etc.)
errors Qué hacer con errores de codificación ('strict', 'ignore', 'replace')

🔓 Modos de apertura

Modo Descripción
'r' Lectura (default). Error si el archivo no existe.
'w' Escritura. Crea el archivo o lo sobreescribe si existe.
'a' Añadir (Append). Escribe al final. Crea el archivo si no existe.
'x' Creación exclusiva. Error si el archivo ya existe.
'r+' Lectura y escritura. El archivo debe existir.
'b' Modo binario (se combina: 'rb', 'wb').
't' Modo texto (default, se combina: 'rt').

Archivos de Texto

Lee y escribe archivos .txt

Un archivo de texto plano contiene caracteres legibles por humanos organizados en líneas. En Python, la manipulación de archivos se basa en el concepto de manejadores de archivos (file handlers) o flujos de datos (streams).

Para interactuar con un archivo, debemos seguir un ciclo de vida:

  1. Abrir el archivo especificando la ruta (path) y el modo (lectura, escritura, etc.).
  2. Procesar (leer el contenido o escribir datos en él).
  3. Cerrar el archivo para liberar los recursos del sistema operativo.

✍️ Escritura de archivos de texto

🔧 write()

Escribe una cadena de texto en el archivo. Regresa un número entero con la cantidad de caracteres escritos.

Sintaxis:

with open(file, "w", encoding="utf-8") as archivo:
	archivo.write(cadena)
Donde:
cadena es el texto str que se escribirá en el archivo. No agrega \n automáticamente.

💻 Ejemplo

Python ejemplo 
with open("saludo.txt", "w", encoding="utf-8") as archivo:
	archivo.write("Hola, mundo\n")
	archivo.write("Segunda línea\n")
	archivo.write("Tercera línea\n")

print("Archivo creado correctamente.")
saludo.txt 
Hola, mundo
Segunda línea
Tercera línea
⚠️ Advertencia:

write() solo acepta cadenas (str). Si intentas escribir un número u otro tipo, lanzará un TypeError: 

f.write(42)        # ❌ TypeError
f.write(str(42))   # ✅ Correcto

📝 Nota importante:
  • write() No agrega salto de línea automáticamente. Si lo necesitas, inclúyelo tú: "\n".
  • Escribe exactamente lo que le pases, sin modificaciones.

🔧 writelines()

Escribe una lista (o cualquier iterable) de cadenas en el archivo, una tras otra. Regresa None.

Sintaxis:

with open(file, "w", encoding="utf-8") as archivo:
    archivo.writelines(iterable)
Donde:
iterable: Lista, tupla o cualquier iterable de cadenas str.

💻 Ejemplo:

Python ejemplo 
lineas = ["Manzana\n", "Plátano\n", "Cereza\n"]

with open("frutas.txt", "w", encoding="utf-8") as archivo:
	archivo.writelines(lineas)
frutas.txt 
Manzana
Banana
Cereza
📝 Nota importante:

writelines() No agrega salto de línea automáticamente. Debes incluir \n en cada elemento de la lista.

Modo 'a' - Agregar sin sobreescribir

Sintaxis:

with open(file, "a", encoding="utf-8") as archivo:
    archivo.write(cadena)

💻 Ejemplo

Python ejemplo 
with open("frutas.txt", "a", encoding="utf-8") as archivo:
    archivo.write("Durazno\n")
    archivo.write("Fresa\n")
frutas.txt 
Manzana
Banana
Cereza
Durazno
Fresa

El contenido anterior de frutas.txt se conserva y las nuevas líneas se agregan al final.

📖 Lectura de archivos de texto

🔧️ read()

Lee todo el contenido del archivo y lo regresa como str con todo el contenido leído.

Sintaxis:

with open(file, "r", encoding="utf-8") as archivo:
    contenido = archivo.read(size=-1)
Donde:
size: Número de caracteres a leer. Sin argumento o -1 lee todo el archivo.

💻 Ejemplo

Python ejemplo 
with open("saludo.txt", "r", encoding="utf-8") as archivo:
    contenido = archivo.read()

print(contenido)
saludo.txt 
Hola, mundo
Segunda línea
Tercera línea

🔧 readline()

Lee una línea del archivo cada vez que se llama, avanzando el cursor internamente.
Regresa str con la línea leída (incluye \n). Retorna "" al llegar al final del archivo.

Sintaxis:

with open(file, "r", encoding="utf-8") as archivo:
    linea = archivo.readline(size=-1)
Donde:
size: Número máximo de caracteres a leer de la línea. Sin argumento lee la línea completa.

💻 Ejemplo:

Python ejemplo 
with open("saludo.txt", "r", encoding="utf-8") as archivo:
    primera = archivo.readline()
    segunda = archivo.readline()
	tercera = archivo.readline()

print(primera.strip())
print(segunda.strip())
print(tercera.strip())
saludo.txt 
Hola, mundo
Segunda línea
Tercera línea

strip() elimina el \n del final antes de imprimir.

📝 Nota:

strip() elimina espacios y \n de ambos extremos de la cadena. Si solo quieres eliminar el salto de línea del final sin tocar posibles espacios al inicio, puedes usar rstrip('\n') que es más preciso: 

primera.rstrip('\n')   # Solo elimina \n al final
primera.strip()        # Elimina espacios y \n en ambos extremos

🔧 readlines()

Lee todas las líneas como una lista.

Sintaxis:

with open(file, "r", encoding="utf-8") as archivo:
    linea = archivo.readlines()

💻 Ejemplo

Python ejemplo 
with open("frutas.txt", "r", encoding="utf-8") as archivo:
    lineas = archivo.readlines()

print(lineas)
frutas.txt 
['Manzana\n', 'Banana\n', 'Cereza\n', 'Durazno\n', 'Fresa\n']

🔄 Iteración directa (la forma más eficiente)

Lee todas las líneas como una lista.

🔤 Sintaxis:

with open(file, "r", encoding="utf-8") as archivo:
    for linea in archivo:
		print(linea.strip())

💻 Ejemplo

Python ejemplo 
with open("frutas.txt", "r", encoding="utf-8") as archivo:
    for linea in archivo:
        print(linea.strip())
frutas.txt 
Manzana
Banana
Cereza
Durazno
Fresa
💡 Dato importante

Cada línea leída de un archivo incluye el carácter \n al final. Usa linea.strip() para eliminar espacios y saltos de línea, o linea.rstrip('\n') para eliminar solo el salto de línea.

⚠️ Precaución:

El modo 'w' es destructivo.
Si abres un archivo existente con open("mi_archivo.txt", "w"), su contenido se borra completamente antes de que escribas algo. Verifica siempre si el archivo existe o usa 'a' si quieres conservar el contenido anterior.

📝 Nota:

Siempre especifica encoding="utf-8".
Si no lo haces, Python usará la codificación por defecto del sistema operativo (que en Windows puede ser cp1252 o latin-1), lo que puede causar errores al leer caracteres como á, é, ñ, ü, etc. Especificar encoding="utf-8" garantiza compatibilidad entre sistemas.

Archivos CSV

Lee y escribe archivos .csv

CSV (Comma-Separated Values, en español, Valores Separados por Comas) es un formato de archivo de texto plano donde los datos están organizados en filas y columnas.
Un archivo CSV es un archivo de texto donde cada línea representa una fila.
Ejemplo: 

nombre,edad,ciudad
Ana,28,Ciudad de México
Luis,35,Guadalajara
María,22,Monterrey

Aunque el nombre dice "coma", el delimitador puede ser cualquier carácter (;, \t, |). Python incluye el módulo csv en su biblioteca estándar, que maneja correctamente casos como:

  • Valores que contienen comas dentro de comillas: "García, Ana"
  • Saltos de línea dentro de un campo
  • Caracteres especiales

📦 Importar el módulo

import csv

No requiere instalación. Es parte de la biblioteca estándar.

✍️ Escritura de archivos CSV

La escritura de archivos CSV en Python permite guardar datos tabulares (filas y columnas) en archivos de texto donde los valores están separados por comas u otros delimitadores.

🏛️ csv.writer

Escribe datos en archivos CSV.

🔤 Sintaxis:

with open("nombre_archivo.csv", mode="w", newline="", encoding="utf-8") as archivo:
    escritor = csv.writer(archivo)

Donde:
nombre_archivo.csv: Nombre del archivo.
mode="w": Modo de apertura.
newline="": Evita el problema de que Python inserte líneas en blanco adicionales entre cada fila en sistemas operativos como Windows.
encoding="utf-8": Asegura el soporte correcto para caracteres especiales, tildes y eñes.
csv.writer(archivo): Crea el objeto escritor encargado de convertir las listas en filas con formato CSV.

💻 Ejemplo:

Python ejemplo 
import csv

datos = [
    ["NOMBRE", "EDAD", "CIUDAD"],          # Encabezado
    ["Ana", 28, "Ciudad de México"],
    ["Luis", 35, "Guadalajara"],
    ["María", 22, "Monterrey"],
]

with open("personas.csv", "w", newline="", encoding="utf-8-sig") as archivo:
    escritor = csv.writer(archivo)
	
	# Escribe todas las filas
    escritor.writerows(datos)

print("CSV creado.")
salida 
CSV creado.

💻 Ejemplo 2:

También puedes escribir fila por fila con writerow():

Python ejemplo 
import csv

with open("personas.csv", "w", newline="", encoding="utf-8-sig") as archivo:
    escritor = csv.writer(archivo)
	
    escritor.writerow(["NOMBRE", "EDAD", "CIUDAD"]) # encabezado
	escritor.writerow(["Ana", 28, "Ciudad de México"])
    escritor.writerow(["Luis", 35, "Guadalajara"])
    escritor.writerow(["María", 22, "Monterrey"])

print("CSV creado.")
salida 
CSV creado.
personas.csv 
NOMBRE,EDAD,CIUDAD
Ana,28,Ciudad de México
Luis,35,Guadalajara
María,22,Monterrey

🏛️ csv.DictWriter

Escribe datos en archivos CSV usando diccionarios.

El método csv.DictWriter() funciona como un traductor automático. A diferencia del csv.writer básico (que necesita que le pases los datos en el orden exacto en el que van a aparecer), DictWriter utiliza las claves (keys) de tus diccionarios para saber exactamente en qué columna debe colocar cada dato, sin importar el orden en el que estén dentro del diccionario.

💻 Ejemplo

Python ejemplo 
import csv

# 1. Define el orden estricto de las columnas (encabezados)
campos = ["NOMBRE", "EDAD", "CIUDAD"]

# 2. Los datos se organizan como diccionarios
personas = [
    {"nombre": "Ana",   "edad": 28, "ciudad": "Ciudad de México"},
    {"nombre": "Luis",  "edad": 35, "ciudad": "Guadalajara"},
    {"nombre": "María", "edad": 22, "ciudad": "Monterrey"},
]

# 3. Abre el archivo y configura el DictWriter
with open("personas.csv", "w", newline="", encoding="utf-8") as archivo:
	# Vincula el archivo con las columnas que elegimos como encabezados
    escritor = csv.DictWriter(archivo, fieldnames=campos)
    
	# 4. Escribe los encabezados (opcional, pero muy recomendado)
	escritor.writeheader()
	
	# 5. Escribe los datos
    escritor.writerows(personas)

print("CSV creado.")
salida 
CSV creado.
personas.csv 
NOMBRE,EDAD,CIUDAD
Ana,28,Ciudad de México
Luis,35,Guadalajara
María,22,Monterrey

📖 Lectura de archivos CSV

🏛️ csv.reader

Lee todo el contenido del archivo y lo regresa como str con todo el contenido leído.

🔤 Sintaxis:

with open(file, "r", encoding="utf-8") as archivo:
    contenido = archivo.read(size=-1)

Donde:
size: Número de caracteres a leer, Sin argumento (o -1) lee todo el archivo.

💻 Ejemplo:

Python ejemplo 
import csv

with open("personas.csv", "r", encoding="utf-8") as archivo:
    lector = csv.reader(archivo)

    for fila in lector:
        print(fila)
salida 
['NOMBRE', 'EDAD', 'CIUDAD']
['Ana', '28', 'Ciudad de México']
['Luis', '35', 'Guadalajara']
['María', '22', 'Monterrey']

💻 Ejemplo 2: Para saltar el encabezado:

Python ejemplo 
import csv

with open("personas.csv", "r", encoding="utf-8") as archivo:
    lector = csv.reader(archivo)
    next(lector)   # Salta la primera fila (encabezado)

    for fila in lector:
        nombre, edad, ciudad = fila
        print(f"{nombre} tiene {edad} años y vive en {ciudad}."))
salida 
Ana tiene 28 años y vive en Ciudad de México.
Luis tiene 35 años y vive en Guadalajara.
María tiene 22 años y vive en Monterrey.

🏛️ csv.DictReader - Lectura como diccionarios

Cada fila se convierte en un diccionario donde las claves son los encabezados. Es la forma más recomendada.

Sintaxis:

with open(file, "r", encoding="utf-8") as archivo:
    linea = archivo.readline(size=-1)

Donde:
size: Número máximo de caracteres a leer de la línea. Sin argumento lee la línea completa.

💻 Ejemplo:

Python ejemplo 
import csv

with open("personas.csv", "r", encoding="utf-8") as archivo:
    lector = csv.DictReader(archivo)

    for fila in lector:
        print(fila["nombre"], "-", fila["ciudad"])
salida 
Ana - Ciudad de México
Luis - Guadalajara
María - Monterrey

💻 Ejemplo 2:

Puedes convertir todas las filas en una lista de diccionarios:

Python ejemplo 
import csv

with open("personas.csv", "r", encoding="utf-8") as archivo:
    lector = csv.DictReader(archivo)
    personas = list(lector)

print(personas[0])
salida 
{'nombre': 'Ana', 'edad': '28', 'ciudad': 'Ciudad de México'}
📝 Nota:

strip() elimina espacios y \n de ambos extremos de la cadena. Si solo quieres eliminar el salto de línea del final sin tocar posibles espacios al inicio, puedes usar rstrip('\n') que es más preciso: 

primera.strip('\n')   # Solo elimina \n al final
primera.rstrip()      # Elimina espacios y \n en ambos extremos

⚙️ Parámetros del dialecto CSV

Puedes personalizar el delimitador, comillas, etc.:

💻 Ejemplo:

Python ejemplo 
import csv

# Leer CSV con punto y coma (común en Europa y LATAM)
with open("datos.csv", "r", encoding="utf-8") as archivo:
    lector = csv.reader(archivo, delimiter=";")
    for fila in lector:
        print(fila)

# Escribir CSV separado por tabulaciones (TSV)
with open("datos.tsv", "w", newline="", encoding="utf-8") as archivo:
    escritor = csv.writer(archivo, delimiter="\t")
    escritor.writerow(["nombre", "edad"])
    escritor.writerow(["Ana", 28])
saludo.txt 
...

Parámetros más usados:

Parámetro Descripción Por defecto
delimiter Carácter separador de campos ','
quotechar Carácter para encerrar campos con el delimitador '"'
quoting Política de uso de comillas QUOTE_MINIMAL
lineterminator Carácter de fin de línea '\r\n'
⚠️ Precaución:

¡No olvides newline="" al abrir un CSV para escritura en Python! 

open("archivo.csv", "w", newline="")  # ✅ Correcto
open("archivo.csv", "w")              # ❌ Genera líneas vacías entre filas en Windows
💡 Tip:

Todos los valores leídos con csv.reader son cadenas (str). Si necesitas números, conviértelos explícitamente: 

edad = int(fila["edad"])
precio = float(fila["precio"])
📝 Nota:

CSV con Excel. Excel en algunas configuraciones suele generar archivos CSV con ; como delimitador (no con ,), porque la coma se usa como separador decimal. Si recibes un CSV de Excel que no se lee bien, prueba con delimiter=";". 

edad = int(fila["edad"])
precio = float(fila["precio"])
